# AGENTS.md

This repository is Nomi, a multi-agent creative intelligence layer.

Core rules:
- Keep canonical Nomi behavior vendor-neutral.
- Prefer one shared skill source over duplicated agent-specific skill logic.
- Use thin adapters only where a host requires special discovery, packaging, or configuration.
- Do not claim compatibility that has not been verified.
- Keep SKILL.md files concise and operational.
- Prefer progressive disclosure through references/scripts.
- Avoid turning Nomi into a design handbook, prompt library, or framework tutorial.
- Every important capability should answer: "What does this make the agent actually do differently?"
